## Short read

- The real cleared analytical spine is: `question -> L0 spec -> L1 research -> citation processing -> L1.5 deliberation -> thin L2 outline -> L4 evaluation -> render-safe markdown + provenance sidecar`.
- The biggest long-term systems that are still not truly there are: governed full-document retrieval, semantic search, Observation Library, rich L3 deliverables, consultant UI, calibration, and production deployment.
- The messiest reconciliation issue is not a missing model or class. It is that the authoritative cleared runtime lives in a sibling worktree/branch, while the current branch and dirty workspace can each tell a different story about readiness.
