# Quality Gates

## Gate 1: Problem Frame

Pass criteria:

- governing question is explicit
- R1 and R2 are stated or flagged as missing
- decision maker and action implication are known or assumed visibly
- scope, time, and accuracy requirements are stated or requested

Fail if the tree begins from a vague topic.

## Gate 2: Axis Selection

Pass criteria:

- 2-3 candidate axes are considered for ambiguous prompts
- selected axis is justified by decision leverage
- rejected axes have clear reasons
- standard frameworks are adapted rather than copied

Fail if the tree jumps straight to a generic framework.

## Gate 3: Sibling Logic

Pass criteria:

- every sibling group declares source logic, truth logic, and evaluation logic when relevant
- branches answer the parent question
- parent summarizes the children without overclaiming
- sequence, structure, class, criteria, diagnostic, or deductive logic is declared

Fail if a level mixes causes, actions, metrics, risks, and stakeholders.

## Gate 4: MECE

Pass criteria:

- sibling branches do not materially overlap
- the relevant universe is covered for the chosen axis
- cross-cutting forces are modeled explicitly
- no obvious gap would change the answer

Fail if MECE is asserted but not operationalized.

## Gate 5: Hypothesis And Decision Relevance

Pass criteria:

- hypotheses are treated as provisional
- must-be-true assumptions are visible
- branches connect to what would prove, disprove, or change the answer
- low-decision-value branches are not overdeveloped

Fail if the tree is exhaustive but not decision-useful.

## Gate 6: Pruning

Pass criteria:

- full tree and pruned tree are separate
- keep/defer/prune/merge decisions are visible
- pruning uses decision impact, uncertainty, evidence cost, and influenceability
- risk of wrong pruning is acknowledged

Fail if pruning happens silently.

## Gate 7: Leaf Actionability

Pass criteria:

- leaves are resolvable by evidence, analysis, or explicit judgment
- evidence and artifact requirements are stated
- disconfirming evidence is included
- expected accuracy level is proportional to decision need

Fail if leaves are vague topics.

## Gate 8: Anti-Genericity

Pass criteria:

- kept top-level branches include named mechanisms, not only category labels
- material branches contain a measurable variable or observable proxy
- material branches state the decision consequence if proven true or false
- at least one disconfirming test is attached to each kept branch family
- domain-specific vocabulary appears because it is analytically necessary, not decorative

Fail if the tree sounds polished but could apply unchanged to many unrelated problems.

## Gate 9: Ambiguity Escalation

Pass criteria:

- unknown decision maker, R1/R2 gap, horizon, action implication, or evidence standard is either answered by an assumption or made into an objective-definition branch
- blocking unknowns are separated from normal evidence questions
- assumptions say how the tree would change if false

Fail if the model silently fills material context gaps with generic consulting defaults.

## Gate 10: Eval Hygiene

Pass criteria:

- examples and archetypes used as priors are not reused as clean benchmark cases
- book-derived evals keep hidden rubrics away from executors
- novel stress tests differ structurally from examples in the skill package
- graders score structural properties rather than resemblance to sample trees

Fail if skill examples contaminate the benchmark pool.
