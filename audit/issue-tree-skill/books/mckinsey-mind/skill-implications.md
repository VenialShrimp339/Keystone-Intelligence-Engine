# Skill Implications

## Required Additions

The skill should include a hypothesis-screening stage:

1. Generate a provisional answer or 2-3 candidate hypotheses when useful.
2. Run a must-be-true assumptions test.
3. Kill weak hypotheses early.
4. Build issue trees around surviving hypotheses or the key uncertainty.

## Leaf Contract

Each leaf should include:

- yes/no or bounded research question
- provisional answer or hypothesis
- analysis needed
- data required
- likely sources
- expected artifact
- decision implication
- disconfirming evidence

## Pruning and Sequencing

The skill should ask:

- Which branches are key drivers?
- Which analyses are quick wins?
- Which questions are dominant and can eliminate downstream work?
- What level of accuracy is required?
- What would it take for this branch to matter?

## Eval Implications

Novel stress tests should grade whether the output:

- moves from hypothesis to issue tree to workplan
- avoids confirmation bias
- does not chase irrelevant analyses
- includes directional accuracy standards
- can be summarized into a concise top-line answer
