# Surprise Register

## 1. The issue tree is the workplan skeleton

The book makes the strongest practical connection between tree leaves and execution. A leaf without a planned analysis, source, and end product is not yet operational.

## 2. Hypothesis-first does not mean answer-first

The hypothesis is a focusing device and can be killed quickly. The skill should present hypotheses as provisional and identify easiest disproofs.

## 3. Asymmetric depth is operationally natural

Conditional yes/no branching creates uneven depth without any special instruction. This is a cleaner justification for asymmetric trees than "senior consultants do lopsided trees."

## 4. Precision is a decision variable

The right level of accuracy depends on how wrong the answer could be before the recommendation changes. This belongs in leaf resolution criteria.

## 5. Communication failure is a diagnostic signal

If the answer cannot be summarized in a top-line claim and a few supporting reasons, the tree likely has a logic problem.

## 6. Triangulation is a tree pattern

For hard-to-measure markets or behaviors, the tree should include parallel bounding paths rather than pretending one source will answer the question.
