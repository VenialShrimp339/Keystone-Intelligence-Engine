# Anti-Patterns

## Vague Problem Statement

Symptoms: no decision maker, no action implication, unclear time frame, no boundaries, no accuracy requirement.

Correction: complete the problem statement contract before decomposing.

## Single-Cut Premature Commitment

Symptoms: model produces one plausible tree immediately and never tests alternative axes.

Correction: force 2-3 candidate cleaving frames for ambiguous problems and compare insight yield.

## Component Tree Frozen As Final Tree

Symptoms: tree remains a list of factors with no hypotheses, no priorities, and no testable leaves.

Correction: migrate factors toward hypotheses, decision criteria, or levers as soon as enough context exists.

## Cross-Cutting Driver As Sibling Branch

Symptoms: policy, technology, regulation, or incentives appear as one top-level branch but also affect all other branches.

Correction: model cross-cutting forces as annotations, constraints, or sub-branches under affected mechanisms.

## Uniform Depth

Symptoms: every branch has the same number of sub-branches regardless of decision relevance.

Correction: deepen high-impact uncertain branches and keep low-value branches shallow.

## Boiling The Ocean With Full Tree

Symptoms: exhaustive tree becomes the research plan without pruning.

Correction: produce full tree first, then pruned decision tree with impact, influenceability, evidence cost, and uncertainty.

## Big-Gun Analysis Before Frame

Symptoms: recommends machine learning, survey work, modeling, or simulations before defining the hypothesis.

Correction: use simple heuristics and summary stats first; escalate only when a specific branch requires it.

## Frame Familiarity Bias

Symptoms: problem is treated as an instance of a known framework because the analyst has seen something similar.

Correction: test whether the frame exposes the actual mechanism and compare against at least one alternative cut.
