# Book Brief: Bulletproof Problem Solving

## Extraction Thesis

Conn and McLean contribute the broadest operating method for the portable issue-tree skill. The book treats problem solving as an iterative cycle: define the problem, disaggregate it, prioritize the high-value branches, build a workplan, conduct fit-for-purpose analyses, synthesize, and tell the story. For this project, the important lesson is that a good issue tree is a working model of the problem that changes as evidence arrives. It is not a one-shot outline.

The book's strongest contribution is "cleaving": choosing the cut through a problem that reveals the levers, constraints, or mechanisms that matter. The same problem can be cut by supply/demand, incidence/severity, component/factor, process, stakeholder, intervention lever, uncertainty level, or decision criteria. Senior judgment shows up in selecting, testing, and revising that cut.

## Senior-Consultant Issue-Tree Lessons

Problem definition determines tree quality. The problem statement should identify the decision maker, decision criteria, boundaries, time frame, accuracy requirement, constraints, and action that will follow. Weak problem statements create wasted analysis.

Use several cuts before committing. The authors repeatedly advise trying two or three tree structures because different frames reveal different insights. This directly supports candidate top-level trees in the skill.

Move from component trees to hypothesis trees. Early trees can be broad factor maps when little is known. As understanding improves, branches should become sharper hypotheses, criteria, or decisions that can be tested.

MECE is necessary but not sufficient. The salmon example shows an early tree can include relevant factors but still overlap, misplace cross-cutting influences such as policy, and hide regional differences or magnitudes. A tree must encode relationships, not just categories.

Prune visibly. Full trees help ensure coverage, but work should focus on branches that materially affect the answer and can be influenced or resolved. The Pacific salmon prioritization uses impact and influenceability as a pruning lens. The solar example shows economics could dominate the decision enough to make other branches secondary unless multiple objectives are active.

Simple analytics first. Before advanced methods, use back-of-the-envelope analysis, summary statistics, heuristics, and "what you have to believe" tests. Advanced analytics should answer a framed question, not substitute for framing.

Synthesis can reveal cross-branch insight. The story is not a reprint of the tree. Findings from different branches often combine into a better explanation or strategy.

## Portable Skill Implications

The skill should:

- produce a strong problem statement before any tree
- propose multiple decomposition axes for ambiguous problems
- distinguish early component/factor trees from later hypothesis, decision, and workplan trees
- require a full tree and pruned tree
- attach pruning rationale based on impact, influenceability, evidence cost, and decision relevance
- treat tree construction as iterative, with explicit "what would change this tree?" checks
- use examples as archetypes of reasoning, not reusable templates
