# Decomposition Axes

Use axes as priors, not templates. For ambiguous problems, compare 2-3 axes before committing.

| Axis | Use When | Watch For |
| --- | --- | --- |
| Component/factor | You barely understand the problem space | Do not freeze as final tree |
| Causal driver | Diagnosing why R1 exists | Do not mix causes and fixes |
| Lever/intervention | Planning actions to reach R2 | Confirm causes first |
| Supply/demand | Capacity, resources, markets | Include matching constraints |
| Incidence/severity | Health, safety, quality, reliability | Severity may be the crux |
| Process/value chain | Operations, service, implementation | Preserve sequence |
| Funnel/conversion | Sales, adoption, recruiting, usage | Include quality/economics |
| Financial equation | Profit, ROI, valuation, unit economics | Put behavior under variables |
| Criteria/option | Choosing among alternatives | Label gates versus weights |
| Stakeholder/incentive | Policy, org change, ecosystems | Stakeholders need mechanisms |
| Constraint gate | Go/no-go choices | Avoid overusing gates |
| Uncertainty strategy | Long horizons, unknown futures | Avoid one base case |
| Portfolio/options | Innovation, investment, philanthropy | Track option value |
| System feedback | Wicked problems, platforms, networks | Linear trees can mislead |
| Evidence sufficiency | Scientific, legal, regulatory questions | Grade evidence quality |
| Comparative benchmark | Performance gaps | Benchmarking is not causation |

## Selection Questions

1. Does the axis answer the governing question?
2. What does it reveal that another axis hides?
3. Are top-level siblings naturally non-overlapping?
4. Does the axis lead to evidence or analysis that can be done?
5. Does a quick calculation or example show this cut will matter?
